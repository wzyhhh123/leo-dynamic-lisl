# N4-P0 因果动态 K 评分接缝

仅工程实现。复用冻结 N1a/N1b/N2/N3，不改生产内核；旧 B4 不调用。
因果视图提供当前业务、终端、预约以及过去发射产生的承诺事件。观察日志构造真实历史注入前缀；deepcopy memo 在复制时替换真 trace 与边界，旧源与含旧源哈希的缓存结果不进入评分对象。
ZERO 仅令未来外生注入为零，PERSIST 延拓当前率。保留 Q/I/A/D、传播 agenda、setup/TX/自然到期、FIFO 与能耗游标；不重新出生 cohort。此为数据引用隔离，不是恶意 Python 的文件系统安全沙箱。
C=J_h+lambda_N*N_end+lambda_E*DeltaE_h；单位 bit·s，lambda_N 为 s，lambda_E 为 bit·s/J。原 320 终端积分；不重复计历史 J/E。
PILOT_ONLY T30/TA20/H6，决策周期3秒，epoch0,3,6,9,12,15,18,21,24,27；t27有效H3，其余H6。真实事件不对齐决策网格。每候选一次真实原子动作后保持，到原评价边界前结束。所有正式科学七参数及正式周期/预算继续null。
全部 N2 合法候选枚举后才保留至多7个，两个公开OD目标优先、字典序确定；REPLACE仍是N2既定生成范围。全部候选同根/同预测，按代价、HOLD平分优先、action_key选取。
