# N4-P0R 精确等价读取接缝与受控成本审计

仅工程优化与受控复测；父修订 0010 的 STOP_COST_EXCESSIVE 结论不被改写。本轮没有完整控制 epoch、六场景 24 次运行、840 分支矩阵、训练或正式科学实验授权。

## 实际接口

`runtime/n4_p0r_reader.py` 提供 PathPins / ReaderLease 路径锁定原型；`runtime/n4_p0r_handle_reader.py` 提供最终 HandleReaderLease。以原始 N1a/N1b/N2/N3/P0 binding 及冻结版本读取器构建上下文，`lease.guard(original)` 返回原 binding 的同类型新对象。只替换该对象的校验入口，不改变原类、不全局替换校验、不修改冻结文件。

新对象仍执行原始 verify 的 schema、独立 manifest 锚、全部文件字节数/SHA-256、配置 null 和授权检查。适配的原始方法与 AST 源码保留在证据中。路径检查在取得全部非 reparse 祖先/文件句柄后复用；最终版每次从已锁定句柄重置读取位置，读取完整原始字节并重新 SHA-256，读取前后检查文件身份、字节数、修改时间。并未缓存文件内容、哈希或“校验通过”结果；JSON 未使用旧解析结果。空文件、任意二进制、CRLF 和跨块文件均须与原读取器完全一致。

打开句柄采用 OPEN_EXISTING、GENERIC_READ、FILE_SHARE_READ、BACKUP_SEMANTICS、OPEN_REPARSE_POINT；拒绝 reparse；任一打开失败都回滚全部句柄。祖先和文件句柄拒绝 WRITE/DELETE 打开，绑定路径不能删除、替换、重命名或切换祖先。用独立测试副本验证写入、替换、删除、祖先重命名、已有 writer 和本机可写映射。不能把普通文件只读属性当作不可变证明。尽管本机已取得映射的测试也拒绝锁定，本接口仍选择每次完整重哈希，不依赖正向验证缓存。

上下文关闭立即失效，克隆只在同一有效读取上下文内共享锁和读取入口；共享文件指针通过 RLock 串行化。本轮只使用一个仿真 worker。跨进程检查点不能序列化这些 Windows 句柄；跨上下文必须重新取得保护并明确重新绑定同样的独立锚，不能直接沿用已关闭入口。该读取层没有流体、调度、FIFO、物理状态或未来真实 trace。

## 不变项

原 N4-P0 的因果视图、ZERO/PERSIST、历史前缀净化、候选顺序、评分公式、证据字段及全部 N2 动作由原函数执行。N2 `_verify`、真实物理窗口、资源事务、真实动作提交、完整状态 SHA、FIFO、能耗、数值闭合均不跳过。没有 SGP4、LOS/FoR 或事务结果缓存。观测其重复键仅用于定位潜在热点，未实现纯几何缓存。

逐字段等价只排除不可确定的墙钟 `timings` 字段；数值不使用新增容差。原测试预期及历史失败不改写。临时计时 observer 只调用原操作一次并返回其真实结果，退出测量时恢复；不属于优化执行路径。

## 受控复测与覆盖边界

以同一个真实 160 星、完整 2742 行 catalog、已有初始跨轨 ACTIVE 连接、t=3 的真实业务前缀，配对 PERSIST/HOLD 的原版和最终接缝；分别运行不带 profiler 与带调用链 profiler 的计时。读取上下文构建、全部原始校验、锁获取及锁后校验单独报告，不能隐藏冷启动成本。

ZERO/PERSIST 共享同一净化当前状态和历史前缀，只分别外推零率与当前率；小域包含显式 HOLD、ADD、DROP、BBM、MBB 五个物理合法动作。全部合法 catalog 数量未完成前为 null；五动作域只是功能及成本诊断，不是全局最优搜索。

完整 N2 catalog 枚举只诊断 60 秒墙钟，在真实不可分割验证之间检查上限。中止时报告实际完成前缀、拒绝原因、方法调用/耗时及重复精确输入键；完整合法数量、全域选择为 null，完整 epoch 数为 0。这个诊断停止时间不进入正式科学搜索预算。不能借此缩小物理 catalog 或声称全覆盖。

## 参数与结论边界

PILOT_ONLY T=30s、T_A=20s、H=6s、cadence=3s、空闲双端 setup=1s、每 epoch 单原子动作；lambda_N=6s、lambda_E=1000 bit·s/J。原 C=J_h+lambda_N N_end+lambda_E DeltaE_h 不变。决策 epoch 为 0,3,6,9,12,15,18,21,24,27；末端 t27 的预测 h=3，其他 h=6。真实注入和终端/传播事件不对齐决策网格。正式科学参数及正式周期/预算仍为 null；3 秒仿真间隔不保证 3 秒墙钟实时性。

仅正确性与成本边界都允许继续时，提出下一轮完整单 epoch 的授权方案。本轮不自动执行完整 epoch，更不据此宣布 N4-P0 完整 Engineering PASS、科学 Gate PASS 或 MPC 优越性。
