# 方法合同草案：基于流体代理模型的滚动时域动态跨轨链路控制

日期：2026-10-13。状态：**METHOD_CONTRACT_DRAFT / NOT_FROZEN / NOT_AUTHORIZED_FOR_IMPLEMENTATION**。

本文件依据用户提供的《系统模型与问题描述》（以下称“系统模型文档”）推导动态跨轨链路控制算法，供用户与导师审定。它不修改生产执行器、E0/E1 frozen manifests 或任何历史合同，不授权启动 Gate E2、Gate F、控制器实现或性能实验。所有带符号的参数均未冻结；第 9 节列出必须由用户决定的事项。

暂定方法名：**FS-RHC**（Fluid-Surrogate Receding-Horizon Control，流体代理滚动时域控制）。

## 1. 从系统模型推出的方法定位

| 系统模型中的设定 | 对算法的含义 |
|---|---|
| 路由与链路容量分配采用统一网络服务机制（3.2节） | 控制器只决定拓扑；每个决策时刻的组合部分是终端级配对，属于匹配问题 |
| 动态终端能耗为状态相关恒定功率（第5节） | 任一动作的增量能耗可由终端状态时间线精确计算，无需学习或估计 |
| 通信目标 \(J_T=\int_0^T N(t)\,dt\)（第4节） | 唯一需要预测的量是拓扑变化对 \(N(t)\) 的影响 |
| 建链有重指向+捕获时长，可见窗口有限（2.1–2.2节） | 收益只在 \([t^{ready},t^{end})\) 内兑现，评价必须分阶段 |
| 不要求全局连通（1.3节末） | 分区代价必须由通信目标自身体现，代理模型须对分区给出有限代价 |
| 因果策略集合 \(\Pi_{causal}\)（第6节） | 只能使用当前及历史观测；轨道几何可预测，未来业务到达不可读取 |

因此算法核心是：**以与仿真器服务机制一致、可闭式计算的流体代理模型预测各候选动作的 \(J\) 变化，结合精确能耗核算，在终端配对约束下滚动选择动作。** 结构上属于 MPC，但预测模型不是完整事件仿真器。

Gate E1 已观察到 setup-induced decision reversal 和共享拥塞外部性（`docs/GATE_E1_MECHANISM_RESULT_CN.md` 第3节）。这说明评价必须包含建链阶段和全网第三方影响，不能只给单条链打局部分数。

## 2. 决策时刻、观测与信息边界

控制器在离散时刻 \(t_n=n\Delta_{dec}\) 决策，\(\Delta_{dec}\) 待定。观测量 \(\mathcal O(t_n)\)：

- 各业务 \(f\) 的节点队列 \(Q_i^f(t_n)\)、在途量 \(I_{ij}^f(t_n)\)、累计注入 \(A_f(t_n)\)；
- 全部动态终端的执行状态、当前绑定、未来预约、已承诺非抢占发送的结束时刻；
- 由 SGP4 预测的终端配对几何窗口 \([t_{uv}^{start},t_{uv}^{end})\) 与 \(\chi_{uv}(t)\)；
- 当前 \(\mathcal L_A(t_n)\)、\(\mathcal L_D(t_n)\)、\(G_{admit}(t_n)\)。

到达率因果估计：

\[
\hat\lambda_f(t_n)=\frac{A_f(t_n)-A_f(t_n-W_{obs})}{W_{obs}},
\]

\(W_{obs}\) 待定。控制器不得读取未来到达轨迹、未来动作、最终 \(J\)、\(B_{tot}\) 实现值或 \(T_A\)（除非第9节明确批准为已知场景参数）。

## 3. 流体代理模型

### 3.1 拓扑到业务服务参数

对任一拓扑 \(G\)，使用**与仿真器相同的路由规则**（第9节决定采用 shortest-propagation 还是 load-aware router）得到每个业务的路径 \(p_f(G)\) 和路径传播时延 \(d_f(G)\)。若 \(o_f\) 与 \(d_f\) 在 \(G\) 中不连通，令 \(r_f(G)=0\)，\(d_f\) 不定义。

端到端服务速率 \(r_f(G)\) 由路径级 progressive filling 计算：积压业务（\(n_f>0\)）需求视为无穷，无积压业务需求为 \(\hat\lambda_f\)，各有向弧容量为 \(C_e\)。这是对仿真器“逐弧 equal-weight work-conserving max-min”的路径级近似，属于声明的近似 A1。

### 3.2 单阶段闭式演化

令业务 \(f\) 在阶段起点的排队积压为 \(n_0=\sum_{i\ne d_f}Q_i^f\)，阶段长度为 \(\Delta\)，净增长率 \(a=\hat\lambda_f-r_f\)。

- 若 \(a\ge 0\)：\(\int n\,dt=n_0\Delta+\tfrac12 a\Delta^2\)，交付速率 \(x_f=r_f\)，阶段末积压为 \(n_0+a\Delta\)。
- 若 \(a<0\)，记 \(t^*=n_0/(-a)\)：
  - \(t^*\ge\Delta\)：同上式，\(x_f=r_f\)；
  - \(t^*<\Delta\)：\(\int n\,dt=\tfrac12 n_0t^*\)，在 \([t^*,\Delta)\) 上 \(n=0\)、\(x_f=\hat\lambda_f\)。
- 分区时 \(r_f=0\)：\(\int n\,dt=n_0\Delta+\tfrac12\hat\lambda_f\Delta^2\)，为有限值。

在途项按 Little 关系近似为 \(\int x_f\,d_f\,dt\)（近似 A2：忽略在途量的瞬态，已发射业务按原日程到达的事实由真实仿真器负责）。多跳中间节点队列聚合为单一业务积压（近似 A3）。

### 3.3 分阶段拓扑与代理目标

对候选动作集合 \(a\)，在预测时域 \([t_n,t_n+H_p)\) 上构造分段常拓扑序列 \(G_0,G_1,\dots\)。分段点包括：

- 现有链路的已知自然到期 \(t^{end}\)（HOLD 基线同样包含）；
- 新链路的预测 \(t^{ready}_{uv}\)（2.2节公式）；
- DROP 链路在 \(t_n\) 立即移出 \(G_{admit}\)（进入 DRAINING 即不接纳新业务）；
- BBM 替换：旧链在 \(t_n\) 移出，新链在 \(t^{ready}\) 加入；MBB 替换：旧链在新链 \(t^{ready}\) 时移出。

各阶段依次应用 3.2 节公式，得到

\[
\hat J(a)=\sum_f\int_{t_n}^{t_n+H_p}\big(n_f(t)+x_f(t)d_f(t)\big)\,dt .
\]

若 \(t_n+H_p\ge T\)，在 \(T\) 处截断并加上残余项 \(\tau_{res}\hat N(T)\)，与系统模型的 \(J_T^+\) 一致。

结构要求：\(H_p\ge \max(\tau^{ret}+\tau^{acq})+\Delta_{dec}\)，否则 ADD 的收益不可见。

### 3.4 精确增量能耗

依据执行器的终端状态时间线，计算动作 \(a\) 相对 HOLD 在 \([t_n,t_n+H_p)\) 内的增量能耗

\[
\Delta\hat E(a)=\sum_{u\in U}\int_{t_n}^{t_n+H_p}\Big(P_{s_u^a(t)}-P_{s_u^{HOLD}(t)}\Big)\,dt ,
\]

其中 DRAINING 按 \(P_{ACTIVE}\) 计费，DRAINING 持续时间取已承诺发送的结束时刻。双端独立计费。执行器给出的状态时间线是唯一权威来源；单端提前完成重指向后的等待状态，以执行器语义为准。

### 3.5 动作代价

\[
\Phi(a)=\hat J(a)+\lambda_E\,\Delta\hat E(a),\qquad
\lambda_E=\frac{(1-\alpha)\,B_{ref}\,D_{ref}}{\alpha\,E_{ref}}\quad[\text{bit·s/J}] .
\]

\(\lambda_E\) 的含义是 1 J 动态终端电能折合多少 bit·s 的未完成业务代价。系统模型第6节使用实现值 \(B_{tot}\) 归一化，但 \(B_{tot}\) 在决策时刻未知；本合同建议以预先声明的 \(B_{ref}\) 替代，见第9节第1项。

## 4. 由目标推出的判定规则（解释性结论）

在单链、业务速率在评价区间内恒定的近似下，记

\[
\Delta P_A=P_{ACTIVE}-P_{IDLE},\qquad
g_l(t)=N(t\mid G\setminus l)-N(t\mid G),
\]

\(E^{set}_l=\sum_{u\in l}\big[(P_{RET}-P_{IDLE})\tau^{ret}_u+(P_{ACQ}-P_{IDLE})\tau^{acq}_l\big]\)。则有：

- **DROP**：ACTIVE 链 \(l\) 满足 \(g_l<2\lambda_E\Delta P_A\) 时值得释放，即其减少的积压不值两端额外维持功耗。
- **ADD**：当且仅当
  \[
  \int_{t^{ready}_l}^{t^{end}_l}g_l\,dt>\lambda_E\big(E^{set}_l+2\Delta P_A L^{usable}_l\big)
  \]
  时值得建立。若 \(\bar g_l>2\lambda_E\Delta P_A\)，可得最短值得建链窗口
  \[
  L^{min}_l=\frac{\lambda_E E^{set}_l}{\bar g_l-2\lambda_E\Delta P_A}.
  \]
  几何可行但 \(L^{usable}_l<L^{min}_l\) 的链不值得建立。
- **REPLACE（BBM）**：新链收益减去旧链在 \([t_n,t^{ready})\) 断开造成的积压增量，再减去 \(\lambda_E E^{set}\)，超过安全余量 \(\delta\) 时才替换。
- **HOLD**：其余情况。

由此预测的可检验机制：低负载时 \(g_l\) 小，\(K(t)\) 下降；热点负载时 \(K(t)\) 上升；\(\alpha\) 减小时 \(K(t)\) 下降。这些是待实验检验的假设，不是已验证结论。算法实现以第5节的完整 \(\Phi\) 为准，本节公式仅用于解释和论文分析。

## 5. 每个决策时刻的算法流程

1. **观测**：读取 \(\mathcal O(t_n)\)，计算 \(\hat\lambda_f\)。
2. **候选生成**：选取满足以下条件的终端对 \((u,v)\)：\(\chi_{uv}(t_n)=1\)；双端均为 IDLE 且未预约，或其一为当前 ACTIVE 绑定（用于 BBM 替换）；\(t^{ready}_{uv}<t^{end}_{uv}\)。之后按 \(L^{usable}\) 与第4节 \(L^{min}\) 的粗估排除，保留至多 \(N_c\) 个，且保持端口多样性。处于 RETARGETING、ACQUIRING、DRAINING 或已预约的终端在第一版中不参与新动作，不中止进行中的建链。
3. **单链权重**：基线为 HOLD 动作 \(a_0\)。对候选新链，\(w_l=\Phi(a_0)-\Phi(a_0\cup\mathrm{ADD}\,l)\)；对现有 ACTIVE 链，\(w_l=\Phi(a_0\cup\mathrm{DROP}\,l)-\Phi(a_0)\)（保持价值）。
4. **匹配提案**：在终端图上以 \(w_l>0\) 的边做最大权匹配，得到提案配置。若某终端在提案中改连新对象，则对应 BBM 替换。
5. **局部改进**：由于链路收益不可加（替代或互补），从 \(a_0\) 出发，依次评估“提案与当前配置的差异动作、单条 DROP、前若干 ADD、MBB 型 REPLACE”中的单步动作。每步以完整 \(\Phi\) 重算，只接受改进超过 \(\delta\) 的最优一步，至多 \(M\) 步。
6. **执行**：动作集合交给现有 B/C 物理与资源验证器。被拒绝的动作移除后，回到第5步继续，不绕过验证。通过的动作交执行器推进。

复杂度：单次 \(\Phi\) 评估为每段一次路由加一次 progressive filling，每个决策时刻的评估次数为 \(O(N_c+M\cdot N_{move})\)。最大权匹配可用 Blossom 算法求解，规模 \(|U|=320\)。

### 5.1 增强变体 FS-RHC+R

在第5步得到的前 \(K_r\) 个动作集合上，用真实仿真器克隆推进 \(H_p\) 后选择 \(J\) 最小者。该变体用于检验代理误差的代价，不作为默认主方法。

## 6. 第一项验证：代理保真度（M0）

M0 应在仿真器正确性验证完成后执行，是方法能否成立的前置条件。

- 从注册状态集合抽取单步动作（ADD、DROP、BBM、MBB 各类），对每个动作分别计算代理 \(\Delta\hat J=\hat J(a)-\hat J(a_0)\) 和真实仿真器在同一 \(H_p\) 上的 \(\Delta J\)。
- 指标：符号一致率、Spearman 秩相关、按动作类型和负载分层的误差，以及分区与非分区状态的分组结果。
- 建议门槛（**待批准，未冻结**）：符号一致率 \(\ge 0.8\)，Spearman \(\rho\ge 0.7\)。
- 若未达门槛：主方法改为“代理筛候选 + 真实 rollout 决策”，或修订近似 A1–A3。不得通过调整门槛使其通过。

## 7. 实验对照（M1–M2，均待授权）

M1 机制检验：在小规模场景验证第4节预测的方向，包括低负载 DROP、热点 ADD、\(L^{min}\) 截断和 \(\alpha\) 对 \(K(t)\) 的影响。

M2 方法比较：

| 编号 | 方法 | 作用 |
|---|---|---|
| B0 | 初始拓扑保持至自然到期，到期后按几何贪心补链 | 静态参照 |
| B1 | 终端能连就连，按剩余窗口最大匹配 | “全开”参照 |
| B2 | 每步按建成后收益最大匹配，忽略建链阶段损失，\(\delta=0\) | 近视切换参照，对应 Celik 2016 指出的问题 |
| B3 | B2 加固定阈值迟滞 | 简单迟滞参照 |
| B4 | Gu 2026 式对偶价格作为链路价值，其余同 FS-RHC | 估值方法消融 |
| P1 | FS-RHC | 主方法 |
| P2 | FS-RHC+R | 预测增量价值检验 |

指标：\(J_T\)、\(J_T^+\)、\(R_{del}(T)\)、\(\bar d_D(T)\)、\(E_{LCT}(T)\)、\(K(t)\) 与 \(K_D(t)\) 轨迹、重构次数（BBM/MBB 分列）、分区时长、单步决策计算时间。\(\alpha\) 扫描给出 \(J\)–\(E\) 折中曲线。

公平性：同初始状态、同轨道、同业务轨迹、同候选规则与预算、同信息边界、同服务机制、同评价窗口 \([0,T]\)。参数（\(\delta\)、\(H_p\)、\(W_{obs}\) 等）只在独立调参种子上选择，测试轨迹不得用于调参。

## 8. 与已有文献的关系（新颖性未审计通过）

- Gu, Park, Choi（arXiv 2601.21914）及 DeepLaDu（arXiv 2601.21921）：单时刻以拉格朗日对偶价格作为链路价值，再做终端匹配，且联合优化路由。本方法的单时刻匹配结构与之相近，不作为贡献；差异在于固定服务机制下的分阶段时序评价。
- Celik, Borst, Whiting, Modiano（Queueing Systems 83, 2016）：重构时延下 Max-Weight 失去吞吐最优性，提出 VFMW/SCB 自适应保持策略。本方法的保持条件由建链时长、有限窗口和能耗价格推出，而不是采用切换曲线；B2/B3 用作对照。
- 待论证的贡献：在双端非零建链、有限可见窗口、DRAINING 和状态能耗下，由流体代理推出的 HOLD/ADD/DROP/REPLACE 判据（含 \(L^{min}\)）及其滚动实现。是否已被既有工作覆盖，仍需针对原文查重。

## 9. 必须由用户决定的事项

1. **归一化**：系统模型第6节使用实现值 \(B_{tot}\)，但它对因果控制器未知。建议改为预先声明的 \(B_{ref}\)，或明确把 \(B_{tot}\) 作为已知场景参数。
2. **\(T_A\) 是否已知**：默认不可知，仅使用 \(\hat\lambda_f\)。
3. **代理所镜像的路由**：shortest-propagation 或 load-aware（Gate E1 两者均已实现）。代理必须与仿真评估使用同一规则。
4. **连通性与能耗形式**：系统模型文档为“不要求连通 + 能耗加权”，`docs/ENERGY_CONSTRAINED_ON_DEMAND_RESEARCH_FRAMEWORK_DRAFT_CN.md` 为“持续连通 + 每星硬预算”。本草案按前者编写；若采用后者，需加入连通维护层，并将每星预算引入为虚拟队列价格 \(\lambda_E+Z_i\)。
5. 第一版是否允许中止进行中的建链，以及是否纳入 MBB 型 REPLACE。
6. 参数：\(\Delta_{dec}\)、\(H_p\)、\(W_{obs}\)、\(\delta\)、\(N_c\)、\(M\)、\(K_r\)，以及各状态功率 \(P_s\) 的来源。
7. M0 门槛和 M2 实验规模。
