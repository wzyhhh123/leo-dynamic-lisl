# 720 星共同模式与结构残差审计

结论：epoch 偏差主要由共同刚体旋转解释，存在很小的结构残差。此前仅凭绝对根数超过 0.001° 推断必须重建 TLE 的结论过强。本次不调整门限、不改写原 TLE 或历史验收结果，也不自动宣告完整 Gate A 通过。

## 分解方法与结果

phase 是瞬时轨道面内相对升交点的 argument of latitude，不是 TLE mean anomaly。目标为 RAAN=10p°、inclination=85°、phase=9s+0.5p°。将目标误差环绕到 [-180°,180°)，取 720 星均值为共同标量偏置，再减去均值得残差。

| 根数 | 共同偏置 ° | 去均值残差最大 ° | RMS ° |
|---|---:|---:|---:|
| RAAN | 0.332336390 | 0.013386247 | 0.009010784 |
| inclination | -0.092194478 | 0.094066997 | 0.045445740 |
| phase | 0.009263378 | 0.152724983 | 0.102777661 |

共同旋转不等于三个根数各加一个常数：参考轴倾斜会按轨道面方向改变升交点与相位原点。因此上述残差不能直接视为结构畸变。

使用各星径向、切向、轨道法向单位三轴，等权拟合一个 determinant=+1 的共同正交旋转，无平移、尺度或逐星自由度。旋转角为 **0.363479031°**。反旋转后，位置方向残差折合距离最大 **14.844 m**、RMS **6.606 m**，保留各星实际半径。

| 根数 | 刚体对齐后去均值最大残差 ° | RMS ° |
|---|---:|---:|
| RAAN | 0.000050544 | 0.000028050 |
| inclination | 0.000050230 | 0.000028391 |
| phase | 0.000101946 | 0.000041543 |

## Candidate set 与 visibility interval

共同正交旋转严格保持两点距离和线段到地心距离，所以当前球形 LOS 与 5000 km cutoff 下，候选集合及连续区间在数学上不变。21 个快照实测候选变化为 0，margin 数值误差最大约 9.1e-12 km。这是同一组轨迹的旋转不变量，不表示旋转初值后重新执行 SGP4 会有完全相同的动力学。

为隔离剩余结构残差，为每星构造从实际 epoch 三轴到“共同旋转后的理想目标三轴”的微小正交校正，固定作用于该星整个原 SGP4 轨迹。它保留径向历史，是几何敏感性对照，**不是另一套物理 SGP4/TLE 资产**，也不是 TwoBody pipeline。它没有独立去除半径、速度大小或长期动力学偏差。

- 比较 0–600 s 全部 258840 对，30 s 扫描、15 s 复核和根细化，无不稳定或 grazing 对。
- 21 个快照候选差异均为 0，Jaccard=1。全对采样距离变化最大 25.679 m。
- 对照仍有 46246 条可见区间，无卫星对发生区间数量变化。
- 22974 个匹配的非截断边界：偏移最大 **0.222925 s**、RMS **0.00993749 s**。边界时间敏感性还取决于阈值附近的距离变化斜率。
- 可见集合在 pair×time 上的对称差为 **51.0145 pair-seconds**，原总量为 20860459.3402 pair-seconds，占 **0.000244551%**。这不是吞吐量损失。

## 验收解释与限制

应分别报告绝对 TEME 取向与允许共同刚体对齐后的 Walker 结构。现有证据支持 rigid/common-mode 主导，不能仅凭绝对根数偏差否决几何资产。是否要求绝对取向仍是合同定义问题，本次未放宽阈值或自动改成 Gate A PASS。

结论限定于 600 s pilot、球形 LOS 和 diagnostic 5000 km；不能推广到全天、地球椭球、地面节点、FOV/姿态或另一套重新拟合的 SGP4 动力学。没有进入业务或控制器实现。
